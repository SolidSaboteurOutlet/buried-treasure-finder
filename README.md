## 📖 About

Buried Treasure Finder calculates the exact buried treasure block position from the world seed, skipping the Explorer Map entirely.

---

## ✨ Features
<a name="features"></a>

- **Exact Block Position** — finds the chest to the block without digging randomly.
- **Explorer Map Skip** — no need to find a shipwreck or ruin first.
- **Heart of the Sea Tracker** — highlights trident and Heart of the Sea loot.
- **Distance Sort** — nearest treasures listed first.
- **Map Markers** — pins on minimap.
- **Chunk Cache** — caches results to avoid re-computation.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
